# SEABINI Production Pipeline Skill

## Pipeline

CONCEPT → SCRIPT → LYRICS → STORYBOARD → CHARACTER REFERENCES →
ENVIRONMENT REFERENCES → ANIMATION → VOICE → MUSIC → SFX → EDIT →
THUMBNAIL → QA → PUBLISH

## Pre-production

For every episode prepare: - final title - learning objective - script -
lyrics - shot list - character list - environments - props - voice
directions - music direction - SFX list - thumbnail concept

## Animation

Use reusable character rigs, reusable environments and reusable actions
wherever possible.

## Audio

Dialogue must remain intelligible above music and sound effects. Keep
voices warm and expressive.

## Editing

Avoid unnecessary rapid cuts. Maintain clear visual cause-and-effect.

## QA checklist

Check: - character consistency - lip-sync/voice timing - audio clarity -
factual accuracy - spelling - visual artifacts - continuity - age
appropriateness - thumbnail readability - no accidental similarity to
third-party IP

## Scaling

Do not produce a large season before validating the pilot. Use audience
retention, repeat viewing, click-through rate and qualitative feedback
to improve the format.
