# SEABINI Visual Prompting Skill

## Global visual style

Use a polished, original preschool 3D animation look: - rounded forms -
expressive faces - soft materials - bright underwater environments -
cinematic but gentle lighting - clean compositions - child-friendly
proportions - readable silhouettes

Do not request "CoComelon style" or reproduce another studio's exact
visual identity.

## Character continuity

Every prompt must preserve the approved character bible: - exact
colors - face shape - eyes - crest/features - body proportions -
fins/limbs - age impression

## Scene prompt structure

1.  Character identity
2.  Action
3.  Emotion
4.  Environment
5.  Camera framing
6.  Lighting
7.  Supporting details
8.  Continuity constraints

## Camera

Prefer wide establishing shots, medium dialogue shots and close-ups for
emotion/discovery.

## Thumbnail rule

Use one dominant character, one clear action or mystery, strong facial
expression and minimal text.

## Negative guidance

Avoid horror, realistic injury, sharp threatening teeth, dark
frightening scenes, clutter, random costumes and inconsistent anatomy.
