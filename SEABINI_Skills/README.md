# SEABINI Skills

This package contains the working skill files for building the SEABINI
preschool ocean entertainment brand.

## Skills

-   seabini-brand --- brand identity and rules
-   character-bible --- character consistency
-   world-building --- reusable ocean world
-   episode-story --- episode structure and scripts
-   songwriting --- original preschool songs
-   visual-prompting --- consistent image/animation prompting
-   production-pipeline --- end-to-end production
-   content-strategy --- channel and season planning
-   quality-control --- final review and publishing gate

Use these as the project rules before creating episodes, songs,
character artwork or production prompts.
